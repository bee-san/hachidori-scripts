# Netflix Subtitle Sidebar

Read Netflix subtitles beside the video. Hover over a word in the current
subtitle or scroll back to an earlier line and look it up with Hachidori as
you would on any page.

1. In Hachidori, open **Settings → Advanced → User scripts → Script Store**,
   select **Check for scripts**, and install **Netflix Subtitle Sidebar**.
2. Enable user scripts in your browser if Hachidori prompts you, then reload
   Netflix.
3. Play a title and choose a subtitle language in Netflix. Use the matching
   Hachidori language profile for lookup.

The panel mirrors the subtitles shown by Netflix and keeps up to 200 lines
from the current title. It sits below the player in narrow windows and
reappears when you exit Netflix's player fullscreen. Hachidori's experimental
Netflix mining switch is optional for sidebar lookup.
