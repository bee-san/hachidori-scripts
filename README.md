# Hachidori Scripts

Community user scripts for [Hachidori](https://github.com/bee-san/hachidori).
A package is JavaScript, CSS or both that changes Hachidori's popup or its
search page.

In Hachidori, switch on Settings → Advanced → Experimental features → Script
Store, then open Advanced → User scripts. **Check for scripts** reads this
repository's [`catalogue.json`](catalogue.json), and **Install** copies a
package into your scripts, where you can switch it off or delete it like your
own. When a package's version changes here, **Update** replaces it.

| Package | What it does |
| --- | --- |
| [Texthooker](scripts/texthooker) | Turns the search page into a texthooker: the lines it keeps, with counts and times, a pause for the Clipboard monitor, and Edit and Delete on each line. |

To add a package, read [CONTRIBUTING.md](CONTRIBUTING.md) and open a pull
request. Bee reviews every package before it is merged.
